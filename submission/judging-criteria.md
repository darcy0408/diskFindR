# Judging Criteria

- Hobby solution: lost disc search is a real disc-golf problem.
- Java 26: Maven release 26, JavaFX 26, structured concurrency preview, records, sealed interfaces, pattern matching.
- End-to-end: Solo Mode inputs to simulation, map, route, and exports.
- UX: guided screens, plain-language warnings, fallback when aerial keys or weather are absent.
- Technical depth: geodesy, wind vectors, simplified flight physics, Monte Carlo uncertainty, covariance ellipses, search-route generation, persistence.
